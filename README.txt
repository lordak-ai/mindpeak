# MindPeak — бесплатный тренажёр памяти

## Содержимое
- index.html — приложение
- manifest.webmanifest — настройки установки как PWA
- sw.js — базовый офлайн-кэш

## Запуск
Откройте index.html в браузере для тестирования.

## Установка на iPhone
Чтобы установить PWA на главный экран, файлы нужно разместить на HTTPS-хостинге (например, GitHub Pages или Netlify):
1. Загрузите все три файла в один публичный проект/сайт.
2. Откройте адрес сайта в Safari на iPhone.
3. Нажмите «Поделиться» → «На экран Домой» → «Добавить».

Прогресс сохраняется в localStorage браузера на этом устройстве. Очистка данных Safari может удалить прогресс.
Это независимый учебный проект, не связанный с Peak.
